# Merchant gateway and test shop (phase 2)

**Run by:** merchants

**Does:** Payment requests, QR codes, pay-by-link, confirmations, refunds.

**Offers interfaces:** I2 (for shop systems)

**Uses interfaces:** I2 (acquiring bank)

Business users have a holding limit of 0: every incoming payment is swept to the giro account.

Status: not started. Build against the contracts in `/contracts`.
