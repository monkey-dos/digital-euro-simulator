# ADR 0002: A game master may create money

Status: accepted (1 November 2026)

## Decision
A game master can top up any account (giro, digital euro or a bank's DCA) at any time.

## Why
Simulations run dry. Without a way to add money, demos stall.

## Consequences
Money creation is impossible in reality. Every top-up is labelled, logged and totalled separately, so the observer can show: money in circulation = all balances = net DCA debits + game-master top-ups.
