# ADR 0005: Holding limit is adjustable

Status: accepted (1 November 2026)

## Decision
The holding limit is a setting of the game master, starting at 3,000 EUR as a placeholder.

## Why
The rulebook does not set an amount. Businesses have a limit of 0 (LM-012-001).

## Consequences
A low limit (e.g. 100 EUR) makes waterfall easy to demonstrate.
