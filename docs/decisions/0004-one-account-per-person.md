# ADR 0004: One digital euro account per person, enforced

Status: accepted (1 November 2026)

## Decision
An individual can hold only one digital euro account. A second account for the same test person fails.

## Why
Rulebook AM-011-001; the PSP must check (AM-011-003/004).

## Consequences
Simulation simplification: the bank asks the central user registry. The real call is in a document we don't have, so the check is a placeholder.
